# G0 立项关卡检查表

## 🎯 关卡目标

将模糊想法转化为明确的问题定义和项目框架，为后续研究和开发奠定基础。

## ✅ 通过标准

### 1. 问题框定 (Problem Framing)

- [ ] **核心问题清晰定义**
  - 问题描述具体且可量化
  - 目标用户群体明确
  - 用户痛点和需求验证
  - 问题的紧迫性和重要性评估

- [ ] **解决方案假设**
  - 初步解决方案概述
  - 核心价值主张定义
  - 差异化竞争优势识别
  - 技术可行性初步评估

### 2. 北极星指标 (North Star Metrics)

- [ ] **关键指标定义**
  - 主要成功指标 (如激活率、留存率、收入等)
  - 指标基线和目标值设定
  - 指标测量方法和数据来源
  - 指标与商业目标的对齐

- [ ] **RICE 优先级评估**
  - Reach (影响用户数量): ___/10
  - Impact (影响程度): ___/10  
  - Confidence (信心度): ___/10
  - Effort (投入成本): ___/10
  - RICE 总分: ___

### 3. 项目范围界定

- [ ] **范围内 (In-Scope)**
  - 核心功能清单
  - MVP 最小可行产品定义
  - 第一阶段交付目标
  - 关键里程碑时间点

- [ ] **范围外 (Out-of-Scope)**
  - 明确不包含的功能
  - 后续版本规划的功能
  - 不考虑的用户群体
  - 技术债务和优化项

### 4. 预算和资源框架

- [ ] **预算限制**
  - 研究阶段预算: ≤ $300
  - 原型开发预算: ≤ $1,000
  - 总项目预算上限: $___
  - 预算分配计划

- [ ] **时间框架**
  - 项目总时长: ___ 天
  - 关键里程碑时间点
  - 团队可投入时间
  - 外部依赖时间要求

- [ ] **团队资源**
  - 核心团队成员和角色
  - 技能要求和能力评估
  - 外部资源需求
  - 顾问和专家支持

## 🚨 拦截条件

以下情况下 **不得通过** G0 关卡:

- [ ] 问题定义模糊或过于宽泛
- [ ] 目标用户群体不明确
- [ ] 缺乏明确的价值主张
- [ ] 北极星指标未定义或不可测量
- [ ] 项目范围边界不清晰
- [ ] 预算超出限制或未明确
- [ ] 高风险项目缺乏缓解方案
- [ ] 团队资源严重不足
