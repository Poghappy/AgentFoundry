# G1 研究关卡检查表

## 🎯 关卡目标

通过系统性研究收集充分证据，验证市场假设，为可行性评估提供数据支撑。

## ✅ 通过标准

### 1. 市场研究 (Market Research)

- [ ] **竞品分析完整**
  - 至少分析 3-5 个直接竞品
  - 功能对比矩阵完成
  - 定价策略和商业模式分析
  - 竞品优劣势评估
  - 市场定位和差异化分析

- [ ] **市场规模评估**
  - TAM (总可获得市场) 数据
  - SAM (可服务市场) 估算
  - SOM (可获得市场) 预测
  - 市场增长趋势分析
  - 市场细分和目标市场确定

### 2. 用户研究 (User Research)

- [ ] **用户需求验证**
  - 用户访谈记录 (至少 5-10 个用户)
  - 用户痛点和需求优先级
  - 用户行为模式分析
  - 用户画像和使用场景
  - 需求紧迫性和支付意愿

- [ ] **用户反馈收集**
  - 现有解决方案使用体验
  - 功能需求和期望
  - 价格敏感度调研
  - 采购决策流程
  - 用户留存和流失原因

### 3. 技术研究 (Technical Research)

- [ ] **技术栈调研**
  - 主流技术方案对比
  - 开源 vs 商业解决方案
  - 技术成熟度和社区支持
  - 性能和扩展性评估
  - 安全性和合规性要求

- [ ] **实现复杂度评估**
  - 核心功能技术难点
  - 第三方服务依赖
  - 数据处理和存储需求
  - 集成和部署复杂度
  - 维护和运营成本

### 4. 商业模式研究

- [ ] **收入模式分析**
  - 订阅 vs 一次性付费
  - 免费增值模式可行性
  - 企业级 vs 个人用户定价
  - 收入预测和增长模型
  - 客户生命周期价值 (LTV)

- [ ] **成本结构分析**
  - 开发和维护成本
  - 基础设施和运营成本
  - 获客成本 (CAC) 估算
  - 人力和管理成本
  - 毛利率和盈利模型

- [ ] 缺乏关键数据的可靠来源
